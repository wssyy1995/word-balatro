main 分支（永远干净源码）
    │
    ├── 日常开发 commit → push
    │
    └── 发版时：
          git checkout -b release/v1.9.5
          运行「游戏深度保护」加固
          微信开发者工具上传 → 提审
          git push origin release/v1.9.5   # 可选：保留混淆版本记录
          
          审核通过后：
          git checkout main
          git branch -D release/v1.9.5     # 删掉 release 分支
